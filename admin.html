Pannello di aggiornamento

Aggiungi, riordina o rimuovi le voci del sito. Le modifiche restano solo in questa pagina finché non scarichi il file e lo sostituisci sul sito pubblicato.

Come si usa
  1. Se il sito è già pubblicato, questa pagina carica automaticamente i contenuti esistenti. Altrimenti, carica qui sotto il tuo data.json attuale (o parti da zero).
  2. Aggiungi le nuove voci con il modulo qui sotto.
  3. Premi «Scarica data.json».
  4. Sostituisci il file data.json nel sito pubblicato (su GitHub: apri il file, icona della matita, incolla il contenuto, salva).
